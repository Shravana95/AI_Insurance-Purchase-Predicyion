# AI_Insurance-Purchase-Predicyion
PROJECT 1 – INSURANCE PURCHASE PREDICTION

Files:
1. insurance_classification.py – main Python program
2. algorithm.txt – exam/report algorithm


Before running:
1. Install pandas, numpy, matplotlib and scikit-learn if needed.
2. Put the dataset CSV in the same folder as the Python file.
3. By default the program looks for Social_Network_Ads.csv.
4. If your dataset has another filename, change DATA_FILE in the first
   section of the program.
5. Run the program.
6. Keep the generated graphs, model_comparison.csv, and
   required_test_case_predictions.csv for the report.
